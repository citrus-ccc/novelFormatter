# Novel Formatter ✍️📚

小説原稿をWeb投稿（小説家になろう・カクヨム等）や商業出版・縦書き組版の業界標準ルールに沿って一括整形し、目次・ルビ付きの **EPUB 3（縦書き／横書き）** として出力できるブラウザ完結型の執筆支援ツールです。

---

## ✨ 主な機能

### 1. 2つの組版モード（横書き ⇔ 縦書き）
* **標準モード（Web小説仕様 / 横書き）：**
  * 地の文同士の無駄な空行を圧縮し、**会話ブロック（「」）の前後にのみ1行空行**を自動挿入。
  * 西暦・日付・時刻・年齢などの数値を**半角算用数字**へ統一（例: `2026年`、`7月29日`、`10時30分`、`26歳`）。
* **縦書き原稿用モード（書籍・出版仕様）：**
  * 商業出版の組版ルールに従い、**会話文前後の空行を詰めて**紙面リズムを最適化。
  * 数値を位取り（十・百・千）を考慮した**漢数字**へ自動変換（例: `二〇二六年`、`七月二十九日`、`十時三〇分`、`二十六歳`）。
    * ※「十日町」などの地名・固有名詞や、縦中横で活かす度量衡（`100km`, `300m`）・秒数（`5秒`）などは自動保護。
  * **出力欄のリアルタイム縦書き表示**：エディタ上で本物の縦書きレイアウトを確認しながら、直接編集やコピーが可能。

### 2. ワンクリック EPUB 3 電子書籍出力
* **完全ローカル生成**：サーバー通信を行わず、JSZipを用いてブラウザ上だけで安全にEPUBファイルをビルド。
* **縦書き／横書きの自動組版**：
  * 縦書き時は**右開き（RTL）**、横書き時は**左開き（LTR）**を自動設定。
* **目次（TOC）自動抽出・階層化**：
  * `# 見出し`、`001： ADHD`、`第1章`、`プロローグ` などを自動検出し、リーダーの目次メニューからジャンプできる章立てを構築（各章ごとに改ページ）。
* **ルビ・傍点の完全再現**：
  * カクヨム傍点（`《《強調》》`）はごま点（`text-emphasis`）、なろう／カクヨムのルビ記法はHTML5の `<ruby>` タグへ変換。
* **縦書き約物・記号の自動最適化**：
  * 三点リーダー（`……`）の中央縦揃え。
  * 見出しのコロン（`：`）を縦書き用の横並び二点（`‥`）へ調整。
  * キーボードショートカット（`Win＋R`）やコマンドオプション（`-s`）、2桁数字の**縦中横（TCY）**。

### 3. こだわりの執筆カスタマイズ
* **見出し前後の空行数指定**：
  * 見出しの前後に空ける行数を自由に指定可能（`0`〜`10`行）。
* **見出し記号の削除＆全角化**：
  * 行頭のMarkdown記号（`#`）だけでなく、独自の見出し記号（`■`、`◆`、`*` 等）を指定して一括削除可能。
  * **全角化オプション（化物語スタイル）**：`001: ADHD` → `００１： ＡＤＨＤ` のように英数字を全角化し、縦書き時に1文字ずつ美しく正立。
* **結びの言葉（完・終・Finなど）の余韻空行保護**：
  * 物語末尾の「完」「終」「Fin」「おわり」などの直前を、他の空行詰め処理から保護し、指定した行数（初期値3行）の余韻空行を自動確保。
* **シーンチェンジ記号の自動整形**：
  * `◇◇◇` や `◆◆◆`、`***` などの場面転換記号の前後に自動で1行空行を挿入し、インデントなしの中央揃えで配置。
* **傍点（ルビ）相互変換**：
  * プルダウンで「なろう形式（`｜傍《・》`）」と「カクヨム形式（`《《傍点》》`）」の相互一括変換に対応。
* **段落頭の自動字下げ**：
  * 会話文や見出し、シーン記号を除く地の文の先頭へ全角スペース（`\u3000`）を一括挿入。

### 4. UI・プライバシー
* **ダーク／ライトテーマ切り替え**（設定はブラウザに自動保存）。
* **完全オフライン動作**：原稿データが外部に送信されることは一切ありません。

## 🚀 使い方

1. **原稿の入力**
   * 左側の「入力」パネルに小説原稿を貼り付けます（なろう形式・カクヨム形式どちらでもOK）。
2. **設定を選ぶ**
   * **Web投稿用**：標準のまま、またはルビ変換プルダウンを選びます。
   * **書籍組版・EPUB用**：「縦書き原稿用モード」にチェックを入れます。
   * 必要に応じて見出し前後の空行数、見出し記号、結びの言葉などの設定を調整します。
3. **実行**
   * **✨ 整形する** をクリックすると、右側の「出力」パネルに整形結果が表示されます。
4. **取得・保存**
   * **📋 結果をコピー**：Web投稿サイト（なろう・カクヨム・ノベルアップ+等）へ貼り付ける際に使用します。
   * **📚 EPUB出力**：書籍タイトルを入力し、各種電子書籍リーダーですぐに読めるEPUBファイルをダウンロードします。

## 📖 EPUBファイルの閲覧について

* **macOS / iOS (iPhone・iPad)**：
  * 標準搭載の **「ブック（Apple Books）」** でそのまま開けます。
* **Windows**：
  * Windowsには標準のEPUBリーダーがないため、以下の無料アプリでの閲覧を推奨します：
    * **[Thorium Reader](https://www.edrlab.org/software/thorium-reader/)**（推奨：縦書き・ルビ・右開き組版の再現度が最も優秀）
    * **紀伊國屋書店 Kinoppy for Windows**
    * **Calibre**
