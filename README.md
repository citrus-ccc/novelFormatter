# Novel Formatter ✍️

小説原稿をWeb投稿（小説家になろう・カクヨム）や縦書き組版の業界標準ルールに沿って一括整形・変換するブラウザツールです。

---

## ✨ 主な機能

* **空行ルールの完全統一**
  * 会話ブロックの前後にのみ適切な空行（1行）を自動挿入
  * 地の文同士の不要な空行を整理し、統一感のある組版へ整形
  * 連続する会話文の間の空行を自動圧縮
* **段落頭の自動字下げ**
  * 会話文やMarkdown見出しを除く地の文の先頭へ、全角スペース（`\u3000`）を一括挿入
* **縦書き ⇔ 横書きの数字自動変換**
  * **縦書きモード（出版ルール）**: 西暦（二〇二六年）、時刻（十時三〇分）、人数（三人）などを適切な漢数字へ変換。度量衡（`100km`, `300m`）や秒数（`5秒`）などの縦中横で活かすべき半角英数字は維持。
  * **横書きモード（Webルール）**: 漢数字で書かれた数字を半角算用数字（2026年、10時30分など）へ強制統一。
* **傍点（ルビ）の相互変換**
  * カクヨム形式（`《《傍点》》`） ⇔ 小説家になろう形式（`｜傍《・》｜点《・》`）のワンクリック相互変換に対応
* **見出し記号（#）の除去オプション**
  * 原稿作成時のMarkdown見出し記号（`# タイトル`）から記号部分のみを削除し、本文に馴染ませる処理が可能
* **完全ローカル動作 & ダーク/ライトテーマ対応**
  * サーバーへのテキスト送信は一切行いません。ブラウザ上だけで安全に完結します。

## 🚀 使い方

1. **原稿の入力**
   * 左側の「入力」パネルに小説原稿を貼り付けます。
2. **設定を選ぶ**
   * 必要に応じてオプションのチェックを切り替えます：
     * 段落先頭を字下げ（全角スペース）
     * 会話ブロック前後に空行
     * 連続する会話の間の空行を詰める
     * **縦書きモード**（数字を漢数字・地の文空行を詰める）
     * 見出し記号（#）を消す
3. **実行する**
   * **✨ 整形する**: 設定したルールに沿って原稿を整形します。
   * **なろう形式に変換**: カクヨム形式の傍点をなろう形式に変換した上で整形します。
   * **カクヨム形式に変換**: なろう形式の傍点をカクヨム形式に変換した上で整形します。
4. **結果をコピー**
   * 「📋 結果をコピー」をクリックしてクリップボードに取得します。
